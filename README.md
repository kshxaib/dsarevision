# DSA Revision 

> **Digital notes for revision — 150 problems divided into 18 patterns.**

A structured revision guide for mastering Data Structures and Algorithms based on the **NeetCode 150** roadmap. Each problem is documented with multiple solution approaches in Java (Brute Force, Better, Optimal), step-by-step intuition, code walkthroughs, and time/space complexity analysis.

---

## ✨ Features

- **18 Core DSA Patterns:** Structured navigation covering every topic from Arrays & Hashing to Dynamic Programming and Bit Manipulation.
- **Multi-Approach Solutions:** Compare **Brute Force**, **Better**, and **Optimal** implementations side-by-side.
- **Java Solutions:** Clean, production-ready Java code with inline comments explaining the core logic.
- **Detailed Complexity Analysis:** Clear breakdown of Time ($O$) and Space ($O$) complexities with explanations.
- **Step-by-Step Walkthroughs:** Bullet-point algorithm traces to solidify understanding before writing code.
- **Interactive Command Palette (`Ctrl + K`):** Quick-jump search across all patterns and problems.
- **LeetCode Integration:** Direct links to original problem statements and test cases.
